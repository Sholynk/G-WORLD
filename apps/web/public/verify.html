Public verification

Verify a certificate

Enter the certificate number, the verification code printed on the certificate, or the code from a student QR card. Verification is public on purpose: an employer should not need a G WORLD account to check a credential.

Codes are case-insensitive. Dashes are optional.

How verification works

  • The certificate lives in the G WORLD database with a unique number and code.
  • Verification reads that record — it does not trust anything printed on paper.
  • Revoked certificates report as revoked, with the reason.
